# 🚨 PRATHAMIKTA

### AI-Powered Disaster & Crisis Response System

**PRATHAMIKTA (प्राथमिकता)** means *Priority*. It is a real-time Emergency Operations Center (EOC) dashboard that collects disaster information from multiple sources, combines duplicate reports, prioritizes incidents, and helps emergency teams respond faster.

## 💡 Key Features

* 📡 **Multi-source data collection** — Sensor data, GDACS, RSS/news feeds, and EOC call logs.
* 🔗 **Incident Fusion** — Combines duplicate reports about the same disaster.
* 🧠 **Priority Scoring** — Uses a transparent multi-factor scoring system to rank incidents.
* 🗺️ **GIS Dashboard** — Displays active incidents and their priority on a map.
* 🚨 **Emergency Alerts** — Sends dispatch notifications to response teams.
* 🤖 **AI Assistant** — Helps EOC operators interact with incident information.

## 🔄 How It Works

```text
Sensors + GDACS + RSS + EOC Calls
              ↓
        Data Collection
              ↓
       Incident Fusion
              ↓
       Priority Scoring
              ↓
        Incident Ranking
              ↓
         EOC Dashboard
              ↓
       Emergency Dispatch
```

## 📊 Current Data

The prototype currently uses **dummy/simulated EOC call logs and sensor data**, while the system is designed to support real-time data sources.
